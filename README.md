## Build on GitHub
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Commit to `main`.
4. Open **Actions**.
5. Select **Build Android APK** and run it if needed.
6. Open the completed workflow run.
7. Under **Artifacts**, download `GitHub-ZIP-Storage-APK`.
8. Extract it and install `app-debug.apk`.

The launcher icon uses the custom portrait + file-management design supplied for this app.
